# 📊 Student Performance Dashboard (Microsoft Excel)

## 📌 Project Overview

The **Student Performance Dashboard** is an interactive Microsoft Excel project designed to analyze and visualize student academic performance. The dashboard transforms raw student data into meaningful insights using Pivot Tables, Pivot Charts, KPI cards, slicers, and conditional formatting.

This project demonstrates how Excel can be used as a powerful Business Intelligence (BI) tool to create professional dashboards for data analysis and decision-making.

---

# 🎯 Objectives

* Analyze student performance using interactive visualizations.
* Monitor important academic KPIs.
* Identify trends and patterns in student data.
* Create a professional and user-friendly dashboard.
* Improve decision-making through data-driven insights.
